# SUVoice

CS310 Mobile Application Development – Term Project

## Description
SUVoice is a Twitter-like social media app built exclusively for the Sabancı University community. Campus conversations are currently scattered across WhatsApp groups and Instagram pages, and there is no shared space limited to verified SU members. SUVoice lets students sign up with their @sabanciuniv.edu email and freely share short posts, like, comment, and follow each other within a campus-only platform.

**Intended users:** Sabancı University students.
